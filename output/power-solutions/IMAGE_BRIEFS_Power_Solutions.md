## USAGE NOTES FOR AI IMAGE GENERATION

### For DALL-E 3:
- Use prompts as written
- Add "photorealistic" or "professional photography" for product shots
- Add "technical diagram" or "engineering schematic" for diagrams
- Request "high resolution" explicitly

### For Midjourney:
- Add parameters: `--ar 16:9` for landscapes, `--ar 1:1` for squares
- Add `--style raw` for more realistic/technical outputs
- Use `--v 6` for latest version
- Add `--q 2` for higher quality

### For Stable Diffusion:
- Use technical/industrial LoRAs if available
- Increase CFG scale for more prompt adherence
- Use negative prompts: "cartoon, anime, watermark, text overlay, low quality"

### General Tips:
1. Generate multiple variations and select best
2. May need to composite multiple generations for complex diagrams
3. Technical diagrams may require manual cleanup in vector software
4. Product photos benefit from actual product reference images as input
