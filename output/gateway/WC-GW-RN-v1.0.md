## 6. Upgrade Instructions

### 6.1 Pre-Upgrade Checklist

> **WARNING: Performing a firmware upgrade during active construction shifts may cause temporary loss of worker tracking data. Schedule upgrades during non-operational windows.**

1. Verify current firmware version via WakeCap Dashboard or gateway CLI: [TBD]
2. Confirm hardware revision is compatible (see Section 5.1)
3. Ensure gateway has stable network connectivity (minimum [TBD] Mbps uplink)
4. Verify gateway battery level is above [TBD]% or unit is connected to mains power
5. Back up current gateway configuration (see Section 6.4)
6. Notify site personnel of planned maintenance window
7. Download firmware image and verify SHA-256 checksum matches value in Section 1

### 6.2 OTA (Over-the-Air) Upgrade Procedure

**Estimated Duration:** [TBD] minutes

1. Log in to the WakeCap Dashboard at [TBD]
2. Navigate to **Gateways > [Target Gateway] > Firmware Management**
3. Upload the firmware image file ([TBD] MB) or select the version from the available releases list
4. Review the pre-upgrade compatibility check results displayed by the dashboard
5. Click **Start Upgrade**
6. Monitor the progress bar -- do not power cycle the gateway during the upgrade

   [IMAGE: WakeCap Dashboard firmware upgrade progress screen]

7. The gateway will automatically reboot upon completion (expected downtime: [TBD] seconds)
8. Verify the new firmware version in the dashboard under **Gateways > [Target Gateway] > Info**
9. Confirm mesh devices reconnect within [TBD] minutes

### 6.3 Manual Upgrade Procedure

> **WARNING: Incorrect manual firmware installation can render the gateway inoperable. Only qualified field engineers should perform this procedure.**

**Required Tools:**

- USB-C cable (data-capable)
- Laptop with [TBD] utility installed (version [TBD] or later)
- Firmware image file (SHA-256 verified)

**Procedure:**

1. Power off the gateway by holding the power button for [TBD] seconds
2. Connect the USB-C cable between the gateway service port and the laptop
3. Launch the [TBD] utility on the laptop
4. Select the gateway from the detected devices list
5. Click **Browse** and select the firmware image file
6. Click **Flash Firmware**
7. Wait for the utility to confirm successful write (expected duration: [TBD] minutes)
8. Disconnect the USB-C cable
9. Power on the gateway
10. Verify the firmware version via the dashboard or gateway CLI

### 6.4 Configuration Backup

Before upgrading, export the current gateway configuration:

1. Via Dashboard: **Gateways > [Target Gateway] > Settings > Export Configuration**
2. Via CLI: `[TBD]`
3. Store the exported configuration file in a secure location

## 7. Rollback Procedure

> **WARNING: Rolling back firmware will revert all configuration changes made after the previous firmware version was installed. Ensure you have a backup of the current configuration before proceeding.**

### 7.1 OTA Rollback

1. Log in to the WakeCap Dashboard
2. Navigate to **Gateways > [Target Gateway] > Firmware Management**
3. Click **Rollback to Previous Version**
4. Confirm the rollback target version: [TBD]
5. Click **Confirm Rollback**
6. Monitor the progress -- expected downtime: [TBD] seconds
7. Verify the restored firmware version in the dashboard
8. Re-apply any configuration changes if necessary

### 7.2 Manual Rollback

1. Follow the Manual Upgrade Procedure (Section 6.3) using the previous firmware image
2. After rollback, restore the configuration backup taken prior to the original upgrade
3. Verify mesh device connectivity and data flow

### 7.3 Rollback Validation

After any rollback, confirm the following:

| Check                         | Expected Result        | Actual Result |
|-------------------------------|------------------------|---------------|
| Firmware version              | [TBD] (previous ver.)  |               |
| Mesh devices connected        | [TBD] devices          |               |
| Cloud data sync               | Active, no errors      |               |
| Alert status                  | No critical alerts     |               |
| Uptime after reboot           | > [TBD] minutes        |               |
