## 1. The Challenge: Connecting Remote Sites to Real-Time Insight

Construction and industrial sites generate vast amounts of environmental and safety data, but that data is only valuable when it reaches the right people at the right time. Remote locations, harsh conditions, and unreliable connectivity create a gap between field sensors and the teams who need to act on the information.

The WakeCap Gateway closes that gap, providing a robust, always-on communication bridge between field-deployed WakeCap devices and the WakeCap Cloud Platform.

---

## 2. Where the Gateway Fits

[IMAGE: System context diagram showing Gateway as the central hub connecting Weather Stations, Smart Hats, Anchors, and MODBUS Assets to the WakeCap Cloud Platform via cellular/Ethernet uplink]

The WakeCap Gateway sits at the heart of every WakeCap deployment:

- **Field devices** (Weather Stations, Smart Hats, Anchors, MODBUS Assets) communicate over the WakeCap mesh network
- **The Gateway** aggregates data from the mesh and transmits it to the cloud
- **The WakeCap Cloud Platform** processes, stores, and visualizes data for end users via the Dashboard and mobile app

## 4. Industry Use Cases

### Construction

- **Site-wide environmental monitoring** — Aggregate weather station data from multiple zones for safety compliance
- **Worker safety tracking** — Relay Smart Hat location and alert data to the command center in real time
- **Remote project oversight** — Give project managers cloud access to on-site conditions without being physically present

- **Remote asset monitoring** — Monitor equipment health data from MODBUS Assets in real time
