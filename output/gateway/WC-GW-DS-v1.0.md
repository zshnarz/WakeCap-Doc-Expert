## 2. Purpose and Key Benefits

The WakeCap Gateway is the central communications hub in the WakeCap IoT ecosystem. It bridges the local wireless mesh network to cloud-based services, enabling real-time monitoring and data aggregation from distributed field devices such as Weather Stations, Smart Hats, Anchors, and MODBUS Assets.

**Key Benefits:**

- Reliable uplink from field mesh network to the WakeCap Cloud platform
- Supports multiple simultaneous device connections across the mesh
- Industrial-grade enclosure rated for harsh outdoor environments
- Remote firmware update and configuration capability
- Automatic failover and store-and-forward data buffering
