# WakeCap Color Codes Quick Reference

Copy-paste ready hex codes for all documentation colors.

---

## Brand Colors

| Name | Hex | Preview |
|------|-----|---------|
| Charcoal Grey (Primary) | `#333333` | Headers, accents |
| Alert Orange | `#FB923C` | Construction accent |

---

## Text Colors

| Name | Hex | Usage |
|------|-----|-------|
| Charcoal | `#212121` | Body text |
| Dark Grey | `#333333` | Secondary text, captions |

---

## Background Colors

| Name | Hex | Usage |
|------|-----|---------|
| White | `#FFFFFF` | Page background |
| Light Gray | `#F5F5F5` | Alt rows, code blocks |
| Border Grey | `#333333` | Dividers, table borders |

---

## Safety Colors (ANSI Z535)

| Signal | Background | Text |
|--------|------------|------|
| DANGER | `#BD2024` | `#FFFFFF` |
| WARNING | `#FF7900` | `#000000` |
| CAUTION | `#EED202` | `#000000` |
| NOTICE | `#333333` | `#FFFFFF` |

---

## Callout Boxes

| Type | Background | Left Border |
|------|------------|-------------|
| Note | `#F5F5F5` | `#333333` |
| Tip | `#F0FDF4` | `#22C55E` |
| Important | `#FDF4FF` | `#A855F7` |
